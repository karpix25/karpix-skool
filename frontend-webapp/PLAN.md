# PLAN: Исправление видимости кода авторизации Telegram

## Проблема
UI для авторизации бота (`setup_code`) скрыт от пользователя, если в его школе 0 студентов. Это блокирует настройку новых школ.

## Этапы исправления

### Phase 1: Анализ (Done)
- [x] Идентификация ошибки: `tenants.find(t => t.member_count > 0)` в `SuperAdmin.tsx` блокирует отображение для новых школ.
- [x] Идентификация ошибки: Ожидание данных от `/tenants` в `Dashboard.tsx` может не срабатывать корректно для новых админов.

### Phase 2: Backend (Backend-Specialist)
- Проверить, что `/tenants` всегда возвращает `setup_code`.
- Убедиться, что даже пустая школа (0 студентов) возвращается в списке `/tenants`.

### Phase 3: Frontend (Frontend-Specialist)
- **SuperAdmin.tsx**:
    - Заменить логику `mySchool = tenants.find(t => t.member_count > 0)` на поиск школы, где текущий пользователь является владельцем (или просто выбор первой доступной школы для админа).
    - Вынести блок **Telegram Setup** в самое начало страницы *My School*, если группа еще не подключена.
- **Dashboard.tsx**:
    - Гарантировать отображение карточки настройки, даже если данных о студентах еще нет.
    - Добавить явную кнопку "Подключить Telegram группу", если `telegram_group_id` отсутствует.

### Phase 4: Тестирование (Test-Engineer)
- Проверить отображение под аккаунтом без школ.
- Проверить отображение под аккаунтом с новой школой (0 студентов).
- Убедиться, что `setup_code` копируется при клике.
